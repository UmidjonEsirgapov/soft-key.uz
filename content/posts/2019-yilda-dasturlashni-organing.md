## Dasturlash olamiga kirib kelish: 2024-yilda qayerdan boshlash kerak?
Dasturlashni o'rganish — bu uzoq va sabr talab qiladigan jarayon. Ishni boshlashdan avval mahalliy IT bozorini tahlil qilish juda muhim. O'zbekistonda Java, PHP, Python va JavaScript eng talabgir tillar hisoblanadi. Bozor holatini kuzatish uchun [Ustoz Shogird](https://t.me/UstozShogird) va [Tashkent developers : Jobs](https://www.facebook.com/groups/tasdev.jobs/) kabi platformalardan foydalanish tavsiya etiladi.

### 6 oylik o'quv rejasi

**1-oy: Asoslar va Internet**
Web texnologiyalari qanday ishlashini tushuning. Buyruqlar qatori (CLI) bilan ishlashni [havola](https://learnpythonthehardway.org/book/appendixa.html) orqali o'rganing. HTML va CSS asoslari, [FreeCodeCamp](http://freecodecamp.org/) platformasidagi bepul darslar orqali bilimingizni mustahkamlang. Yodlashga emas, tushunishga harakat qiling.

**2-oy: JavaScript sari ilk qadamlar**
JavaScript — bu webning yuragi. [Zamonaviy JavaScript](https://learn.javascript.ru/) resursi orqali tilning ishlash mexanizmlari va DOM (Document Object Model) bilan [websahifani](https://www.w3schools.com/js/js_htmldom.asp) qanday boshqarishni o'rganing.

**3-oy: ES6+ va Versiya nazorati**
Zamonaviy standartlar bilan tanishing ([website](https://flaviocopes.com/ecmascript/)). Git va GitHub'dan foydalanishni o'rganib, barcha loyihalaringizni yuklab boring. [Havola](https://www.youtube.com/playlist?list=PL0eyrZgxdwhwNC5ppZo_dYGVjerQY3xYU) orqali vizual darslarni tomosha qiling.

**4-oy: Amaliyot va NPM**
Nazariyani amaliyotga ko'chiring. [Murakkablashgan JavaScript](https://www.udemy.com/advanced-javascript-concepts/?couponCode=TOP10INJS) kursi yordamida chuqurroq bilim oling. [Mozila Dev](https://developer.mozilla.org/en-US/) sahifasidan doimiy foydalaning. 

**5-oy: Kutubxonalar va Deploy**
React.js'ni o'zlashtiring ([kursni](https://www.udemy.com/modern-javascript-the-complete-course-build-10-projects)). Loyihalaringizni [Netlify](http://netlify.com/) orqali internetga chiqaring.

**6-oy: Backend bilan aloqa**
[HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP), [JSON](https://www.w3schools.com/js/js_json_intro.asp) va [AJAX](https://www.w3schools.com/xml/ajax_intro.asp) orqali [API server](https://hackernoon.com/restful-api-design-with-node-js-26ccf66eab09) bilan ishlashni o'rganing. 

### Xulosa
Dasturlashda depressiya va tushkunlik tabiiy hol. Asosiysi — to'xtab qolmaslik va doimiy amaliyot qilish. Qo'shimcha ma'lumot olish uchun [havola](https://medium.com/zerotomastery/learn-to-code-in-2019-get-hired-and-have-fun-along-the-way-d4197f96be27) va [Shokhrukh Khalilov(Muhammadxalil)](https://medium.com/alidesign/2019-yilda-dasturlashni-organing-9c149555f323) maqolalarini o'qib chiqishni maslahat beramiz. Robototexnikaga qiziqsangiz, [Johnny Fife](http://johnny-five.io/) loyihasi sizga yordam beradi.
